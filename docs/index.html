ESP32 Bluetooth Presence Detector

Web-based firmware installer

1 Flash Firmware

Connect your ESP32 via USB and click the button below to install the firmware directly from your browser.

Browser Not Supported

Web Serial is not supported in this browser. Please use Chrome or Edge on desktop.

Access Denied

Serial port access was denied. Please allow access and try again.

Requirements

  • Chrome or Edge browser (desktop)
  • ESP32 connected via USB
  • USB drivers installed (CP210x or CH340)

2 Configure Device

After flashing, the ESP32 will create a WiFi network for configuration:

Setup Instructions

  1. Connect to WiFi network ESP32_Presence_Setup
  2. Open browser and go to http://192.168.4.1
  3. Enter your WiFi, MQTT, and optional static IP settings
  4. Click Save - device will restart and connect to your network

3 Start Using

Once configured, the device will publish presence data via MQTT. Control it using these topics:

Scan Presence

.../scan/request

Add Device

.../config/add

Pairing Mode

.../pairing/set

Factory Reset

.../system/factory_reset

Features

Bluetooth Classic

Detects phones via Bluetooth name request

MQTT Integration

Works with Home Assistant

Web Provisioning

Easy WiFi/MQTT setup via captive portal

Static IP Support

Optional fixed IP configuration

Dynamic Config

Add/remove phones via MQTT

Factory Reset

Hold BOOT button for 5 seconds
